# داده ساختار های مقدماتی

## ساختمان داده‌های پایه (Basic Data Structures)

در بسیاری از مسائل برنامه‌نویسی، تنها دانستن الگوریتم‌ها کافی نیست و انتخاب ساختمان داده‌ی مناسب نیز نقش بسیار مهمی در سرعت و سادگی پیاده‌سازی دارد. یک **ساختمان داده (Data Structure)** روشی برای ذخیره و سازمان‌دهی اطلاعات است تا بتوان عملیات‌هایی مانند درج، حذف، جستجو یا دسترسی به عناصر را با سرعت مناسبی انجام داد. ممکن است دو الگوریتم دقیقاً یک ایده‌ی یکسان داشته باشند، اما استفاده از ساختمان داده‌ی مناسب باعث شود یکی در زمان قابل قبول اجرا شود و دیگری با خطای **Time Limit Exceeded (TLE)** مواجه گردد. به همین دلیل، آشنایی با ساختمان داده‌های استاندارد کتابخانه‌ی STL یکی از مهم‌ترین مهارت‌های موردنیاز در برنامه‌نویسی مسابقه‌ای است.

در این فصل با تعدادی از پرکاربردترین ساختمان داده‌های STL آشنا می‌شویم، نحوه‌ی استفاده از آن‌ها را یاد می‌گیریم و مهم‌ترین توابع هر کدام را بررسی خواهیم کرد.

---

## Stack

**Stack** یا **پشته** یکی از ساده‌ترین ساختمان داده‌ها است که از قانون **Last In First Out (LIFO)** پیروی می‌کند؛ یعنی آخرین عنصری که وارد پشته شده است، اولین عنصری خواهد بود که از آن خارج می‌شود. می‌توان Stack را مانند دسته‌ای از بشقاب‌ها در نظر گرفت؛ هر بشقاب جدید روی بالای دسته قرار می‌گیرد و هنگام برداشتن نیز همیشه بشقاب بالایی برداشته می‌شود. این ساختمان داده در پیاده‌سازی DFS، بررسی صحت پرانتزها، محاسبه‌ی عبارات ریاضی، بازگشت از توابع بازگشتی و بسیاری از الگوریتم‌های دیگر کاربرد دارد.

برای استفاده از Stack در C++ کافی است کتابخانه‌ی زیر را اضافه کنیم.

```cpp
#include <stack>
using namespace std;
```

سپس می‌توان یک Stack از نوع `int` به صورت زیر تعریف کرد.

```cpp
stack<int> st;
```

مهم‌ترین توابع Stack عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن عنصر به بالای Stack |
| `pop()` | حذف عنصر بالایی |
| `top()` | مشاهده‌ی عنصر بالایی |
| `empty()` | بررسی خالی بودن Stack |
| `size()` | تعداد عناصر Stack |

نمونه‌ی استفاده:

```cpp
stack<int> st;

st.push(10);
st.push(20);
st.push(30);

cout << st.top() << '\n';

st.pop();

cout << st.top() << '\n';
```

خروجی برنامه برابر است با:

```text
30
20
```

تمام عملیات‌های اصلی Stack شامل `push`، `pop` و `top` در مرتبه‌ی زمانی

$$
O(1)
$$

انجام می‌شوند.

!!! note "نکته"

    در Stack تنها به عنصر بالایی دسترسی داریم و امکان دسترسی مستقیم به سایر عناصر وجود ندارد. اگر به پیمایش یا دسترسی تصادفی نیاز داشته باشیم، باید از ساختمان داده‌های دیگری مانند `vector` یا `deque` استفاده کنیم.

## Queue

**Queue** یا **صف** نیز یکی دیگر از ساختمان داده‌های پایه است که از قانون **First In First Out (FIFO)** پیروی می‌کند؛ یعنی اولین عنصری که وارد صف می‌شود، اولین عنصری نیز خواهد بود که از آن خارج می‌شود. صف را می‌توان مانند صف افراد در بانک یا فروشگاه در نظر گرفت؛ هر شخص جدید در انتهای صف قرار می‌گیرد و خدمت‌رسانی همیشه از ابتدای صف انجام می‌شود. Queue در بسیاری از الگوریتم‌ها مانند BFS، شبیه‌سازی صف انتظار، زمان‌بندی پردازه‌ها و بسیاری از مسائل مربوط به پردازش ترتیبی داده‌ها کاربرد دارد.

برای استفاده از Queue کافی است بنویسیم:

```cpp
#include <queue>
using namespace std;
```

تعریف یک Queue از اعداد صحیح:

```cpp
queue<int> q;
```

مهم‌ترین توابع Queue عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن عنصر به انتهای صف |
| `pop()` | حذف عنصر ابتدای صف |
| `front()` | مشاهده‌ی اولین عنصر |
| `back()` | مشاهده‌ی آخرین عنصر |
| `empty()` | بررسی خالی بودن صف |
| `size()` | تعداد عناصر صف |

نمونه‌ی استفاده:

```cpp
queue<int> q;

q.push(5);
q.push(8);
q.push(12);

cout << q.front() << '\n';

q.pop();

cout << q.front() << '\n';
```

خروجی:

```text
5
8
```

همانند Stack، تمام عملیات اصلی Queue نیز در مرتبه‌ی زمانی

$$
O(1)
$$

انجام می‌شوند.

!!! tip "کاربرد"

    اگر مسئله‌ای ترتیب ورود عناصر را حفظ می‌کند و عناصر باید دقیقاً به همان ترتیبی که وارد شده‌اند پردازش شوند، معمولاً Queue انتخاب مناسبی خواهد بود. مشهورترین مثال آن الگوریتم **BFS** است که رأس‌ها را دقیقاً به ترتیب کشف شدن پردازش می‌کند.
## Deque

**Deque** که مخفف عبارت **Double Ended Queue** است، ساختمانی داده‌ای شبیه Queue محسوب می‌شود، با این تفاوت که عملیات درج و حذف را از هر دو انتهای آن می‌توان انجام داد. به عبارت دیگر، علاوه بر اضافه کردن عنصر به انتهای صف، می‌توان عنصر جدید را در ابتدای آن نیز قرار داد و همچنین حذف عناصر نیز از هر دو سمت امکان‌پذیر است. این ویژگی باعث می‌شود Deque انعطاف بیشتری نسبت به Queue داشته باشد و در مسائلی مانند Sliding Window، الگوریتم Monotonic Queue و برخی شبیه‌سازی‌ها کاربرد فراوانی داشته باشد.

برای استفاده از Deque کافی است کتابخانه‌ی زیر را اضافه کنیم.

```cpp
#include <deque>
using namespace std;
```

تعریف یک Deque از نوع `int`:

```cpp
deque<int> dq;
```

مهم‌ترین توابع Deque عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `push_front(x)` | افزودن عنصر به ابتدای Deque |
| `push_back(x)` | افزودن عنصر به انتهای Deque |
| `pop_front()` | حذف اولین عنصر |
| `pop_back()` | حذف آخرین عنصر |
| `front()` | مشاهده‌ی اولین عنصر |
| `back()` | مشاهده‌ی آخرین عنصر |
| `empty()` | بررسی خالی بودن Deque |
| `size()` | تعداد عناصر |

نمونه‌ی استفاده:

```cpp
deque<int> dq;

dq.push_back(3);
dq.push_back(5);
dq.push_front(1);

cout << dq.front() << ' ' << dq.back() << '\n';

dq.pop_front();
dq.pop_back();

cout << dq.front() << '\n';
```

خروجی:

```text
1 5
3
```

تمام عملیات درج و حذف از ابتدا و انتهای Deque در مرتبه‌ی زمانی

$$
O(1)
$$

انجام می‌شوند.

!!! note "نکته"

    برخلاف `queue`، در `deque` علاوه بر ابتدا و انتها، امکان دسترسی تصادفی به عناصر نیز وجود دارد؛ بنابراین می‌توان مانند یک آرایه از عملگر `[]` نیز استفاده کرد.

## Priority Queue (Heap)

گاهی در یک مسئله لازم نیست عناصر دقیقاً به ترتیب ورود یا خروج پردازش شوند، بلکه همواره می‌خواهیم **بزرگ‌ترین** یا **کوچک‌ترین** عنصر موجود را با بیشترین سرعت در اختیار داشته باشیم. برای این منظور از **Priority Queue** استفاده می‌شود که معمولاً با استفاده از ساختمان داده‌ی **Heap** پیاده‌سازی می‌شود.

در پیاده‌سازی پیش‌فرض STL، `priority_queue` یک **Max Heap** است؛ یعنی بزرگ‌ترین عنصر همیشه در ابتدای صف قرار دارد و با هر بار حذف، بزرگ‌ترین عنصر موجود خارج می‌شود.

برای استفاده از آن:

```cpp
#include <queue>
using namespace std;
```

تعریف یک Max Heap:

```cpp
priority_queue<int> pq;
```

مهم‌ترین توابع آن عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن عنصر |
| `pop()` | حذف بزرگ‌ترین عنصر |
| `top()` | مشاهده‌ی بزرگ‌ترین عنصر |
| `empty()` | بررسی خالی بودن |
| `size()` | تعداد عناصر |

نمونه‌ی استفاده:

```cpp
priority_queue<int> pq;

pq.push(7);
pq.push(2);
pq.push(15);
pq.push(10);

cout << pq.top() << '\n';

pq.pop();

cout << pq.top() << '\n';
```

خروجی:

```text
15
10
```

عملیات `push` و `pop` در Heap دارای مرتبه‌ی زمانی

$$
O(\log n)
$$

و مشاهده‌ی بزرگ‌ترین عنصر با استفاده از `top` در مرتبه‌ی

$$
O(1)
$$

انجام می‌شود.

### Min Heap

در بسیاری از مسائل، به جای بزرگ‌ترین عنصر، لازم است کوچک‌ترین عنصر را با سرعت بالا در اختیار داشته باشیم. برای این منظور می‌توان با استفاده از `greater` یک **Min Heap** ایجاد کرد.

```cpp
priority_queue<
    int,
    vector<int>,
    greater<int>
> pq;
```

نمونه:

```cpp
priority_queue<
    int,
    vector<int>,
    greater<int>
> pq;

pq.push(7);
pq.push(2);
pq.push(15);

cout << pq.top() << '\n';
```

خروجی:

```text
2
```

!!! tip "کاربرد"

    Priority Queue یکی از پرکاربردترین ساختمان داده‌ها در برنامه‌نویسی مسابقه‌ای است و در الگوریتم‌هایی مانند **Dijkstra**، **Prim**، **Huffman**، زمان‌بندی پردازه‌ها و بسیاری از مسائل مربوط به انتخاب بهترین عنصر در هر مرحله استفاده می‌شود.
## Set

**Set** یکی از پرکاربردترین ساختمان داده‌های STL است که مجموعه‌ای از عناصر **یکتا** را به صورت **مرتب‌شده** نگهداری می‌کند. به عبارت دیگر، اگر یک مقدار را چندین بار در Set وارد کنیم، تنها یک نسخه از آن ذخیره خواهد شد. همچنین عناصر همواره بر اساس عملگر `<` مرتب می‌شوند و می‌توان به سرعت کوچک‌ترین، بزرگ‌ترین یا اولین عنصر بزرگ‌تر یا مساوی یک مقدار مشخص را پیدا کرد. در STL، `set` معمولاً با استفاده از درخت **Red-Black Tree** پیاده‌سازی می‌شود؛ بنابراین تمام عملیات اصلی آن در مرتبه‌ی زمانی

$$
O(\log n)
$$

انجام می‌شوند.

برای استفاده از Set کافی است بنویسیم:

```cpp
#include <set>
using namespace std;
```

تعریف یک Set:

```cpp
set<int> st;
```

مهم‌ترین توابع آن عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `insert(x)` | اضافه کردن عنصر |
| `erase(x)` | حذف عنصر |
| `find(x)` | پیدا کردن عنصر |
| `count(x)` | بررسی وجود عنصر |
| `lower_bound(x)` | اولین عنصر بزرگ‌تر یا مساوی `x` |
| `upper_bound(x)` | اولین عنصر بزرگ‌تر از `x` |
| `begin()` | اولین عنصر |
| `end()` | انتهای مجموعه |
| `empty()` | بررسی خالی بودن |
| `size()` | تعداد عناصر |

نمونه‌ی استفاده:

```cpp
set<int> st;

st.insert(5);
st.insert(2);
st.insert(8);
st.insert(5);

for (int x : st)
    cout << x << ' ';
```

خروجی:

```text
2 5 8
```

همان‌طور که مشاهده می‌شود، مقدار `5` تنها یک بار در مجموعه ذخیره شده است.

بررسی وجود یک عنصر:

```cpp
if (st.count(5))
    cout << "YES\n";
```

یا:

```cpp
if (st.find(5) != st.end())
    cout << "YES\n";
```

پیدا کردن اولین عنصر بزرگ‌تر یا مساوی `x`:

```cpp
auto it = st.lower_bound(6);

if (it != st.end())
    cout << *it;
```

در مثال بالا خروجی برابر با `8` خواهد بود.

!!! note "نکته"

    از آنجا که عناصر Set همیشه مرتب هستند، هنگام پیمایش مجموعه، عناصر به ترتیب صعودی مشاهده خواهند شد.

## Multiset

**Multiset** تقریباً مشابه Set است، با این تفاوت که اجازه‌ی ذخیره‌ی چندین نسخه از یک مقدار را می‌دهد. بنابراین اگر یک عدد چند بار در Multiset درج شود، تمام نسخه‌های آن نگهداری خواهند شد. این ساختمان داده نیز مانند Set بر پایه‌ی درخت متوازن پیاده‌سازی شده است و تمام عملیات اصلی آن دارای مرتبه‌ی زمانی

$$
O(\log n)
$$

هستند.

برای تعریف آن:

```cpp
multiset<int> ms;
```

نمونه:

```cpp
multiset<int> ms;

ms.insert(5);
ms.insert(5);
ms.insert(2);
ms.insert(5);

for (int x : ms)
    cout << x << ' ';
```

خروجی:

```text
2 5 5 5
```

بیشتر توابع `multiset` دقیقاً مشابه `set` هستند، اما تفاوت مهمی در تابع `erase` وجود دارد.

اگر بنویسیم:

```cpp
ms.erase(5);
```

تمام عناصر با مقدار `5` حذف خواهند شد.

اما اگر تنها بخواهیم یکی از آن‌ها حذف شود، باید ابتدا Iterator آن را پیدا کنیم.

```cpp
auto it = ms.find(5);

if (it != ms.end())
    ms.erase(it);
```

این بار تنها یک نسخه از مقدار `5` حذف خواهد شد.

!!! tip "کاربرد"

    `multiset` زمانی مناسب است که علاوه بر مرتب بودن عناصر، لازم باشد مقادیر تکراری نیز نگهداری شوند. برای مثال، در بسیاری از مسائل Sliding Window یا نگهداری مجموعه‌ای از اعداد با امکان حذف و درج سریع، استفاده از `multiset` بسیار رایج است.

## Map

در بسیاری از مسائل لازم است برای هر مقدار، یک اطلاعات دیگر نیز ذخیره کنیم. برای مثال ممکن است بخواهیم نام یک دانش‌آموز را به نمره‌ی او، یا شماره‌ی یک رأس را به مقدار DP آن نگاشت کنیم. برای این منظور از **Map** استفاده می‌شود. `map` مجموعه‌ای از زوج‌های

$$
(\text{Key},\text{Value})
$$

را نگهداری می‌کند که کلیدها یکتا بوده و همواره به صورت مرتب ذخیره می‌شوند. همانند `set`، پیاده‌سازی `map` نیز معمولاً بر پایه‌ی Red-Black Tree است و عملیات اصلی آن در مرتبه‌ی زمانی

$$
O(\log n)
$$

انجام می‌شود.

تعریف یک Map:

```cpp
map<string, int> mp;
```

درج مقدار:

```cpp
mp["Ali"] = 18;
mp["Sara"] = 20;
```

خواندن مقدار:

```cpp
cout << mp["Ali"];
```

خروجی:

```text
18
```

مهم‌ترین توابع Map عبارت‌اند از:

| تابع | توضیح |
|------|-------|
| `insert()` | درج عضو |
| `erase()` | حذف عضو |
| `find()` | پیدا کردن کلید |
| `count()` | بررسی وجود کلید |
| `operator[]` | خواندن یا تغییر مقدار |
| `begin()` | اولین عضو |
| `end()` | انتهای Map |

پیمایش Map:

```cpp
for (auto x : mp)
    cout << x.first << " " << x.second << '\n';
```

که در آن:

- `first` برابر کلید است.
- `second` برابر مقدار متناظر با آن کلید است.

!!! note "نکته"

    اگر از عملگر `[]` برای کلیدی استفاده شود که قبلاً در Map وجود نداشته است، آن کلید به صورت خودکار ایجاد خواهد شد و مقدار اولیه‌ی آن برابر مقدار پیش‌فرض نوع داده خواهد بود.
## Unordered Set و Unordered Map

تا اینجا با `set` و `map` آشنا شدیم که عناصر را به صورت مرتب نگهداری می‌کنند. اما در بسیاری از مسائل، مرتب بودن عناصر اهمیتی ندارد و تنها به دنبال سریع‌ترین زمان ممکن برای عملیات درج، حذف و جستجو هستیم. در چنین شرایطی می‌توان از **`unordered_set`** و **`unordered_map`** استفاده کرد. این ساختمان داده‌ها بر پایه‌ی **Hash Table** پیاده‌سازی شده‌اند و برخلاف نسخه‌های معمولی، ترتیب خاصی برای عناصر حفظ نمی‌کنند. در حالت معمول، عملیات اصلی آن‌ها در مرتبه‌ی زمانی

$$
O(1)
$$

انجام می‌شود که آن‌ها را به یکی از سریع‌ترین Containerهای STL تبدیل می‌کند.

برای استفاده از آن‌ها کافی است کتابخانه‌ی زیر را اضافه کنیم.

```cpp
#include <unordered_set>
#include <unordered_map>
using namespace std;
```

تعریف آن‌ها:

```cpp
unordered_set<int> st;

unordered_map<string, int> mp;
```

تقریباً تمام توابع آن‌ها مشابه نسخه‌های معمولی است.

برای مثال:

```cpp
unordered_set<int> st;

st.insert(5);
st.insert(10);

if (st.count(5))
    cout << "YES\n";
```

و یا:

```cpp
unordered_map<string, int> mp;

mp["Ali"] = 18;
mp["Sara"] = 20;

cout << mp["Sara"];
```

در حالت عادی، عملیات‌های `insert`، `erase` و `find` همگی دارای مرتبه‌ی زمانی

$$
O(1)
$$

هستند، اما در بدترین حالت ممکن، اگر تعداد زیادی از عناصر در یک خانه‌ی جدول Hash قرار بگیرند، این مرتبه می‌تواند به

$$
O(n)
$$

افزایش یابد. البته در عمل، این اتفاق بسیار نادر است و به همین دلیل `unordered_set` و `unordered_map` در بسیاری از مسائل مسابقه‌ای سریع‌تر از نسخه‌های مرتب خود هستند.

!!! note "نکته"

    از آنجا که عناصر در Hash Table ذخیره می‌شوند، هنگام پیمایش `unordered_set` یا `unordered_map` هیچ ترتیب مشخصی برای عناصر وجود ندارد و حتی ممکن است این ترتیب در اجرای‌های مختلف برنامه تغییر کند.

## مقایسهٔ ساختمان داده‌ها

هر یک از ساختمان داده‌های معرفی‌شده برای هدف خاصی طراحی شده‌اند و انتخاب مناسب آن‌ها می‌تواند تأثیر قابل توجهی بر سادگی پیاده‌سازی و سرعت اجرای برنامه داشته باشد. جدول زیر خلاصه‌ای از مهم‌ترین ویژگی‌های آن‌ها را نشان می‌دهد.

| ساختمان داده | مرتب | عناصر تکراری | درج | حذف | جستجو |
| :--- | :---: | :---: | :---: | :---: | :---: |
| `stack` | ✗ | ✓ | $O(1)$ | $O(1)$ | فقط رأس |
| `queue` | ✗ | ✓ | $O(1)$ | $O(1)$ | فقط ابتدا |
| `deque` | ✗ | ✓ | $O(1)$ | $O(1)$ | $O(1)$ |
| `priority_queue` | بر اساس اولویت | ✓ | $O(\log n)$ | $O(\log n)$ | $O(1)$ برای `top` |
| `set` | ✓ | ✗ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ |
| `multiset` | ✓ | ✓ | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ |
| `map` | ✓ | کلید یکتا | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ |
| `unordered_set` | ✗ | ✗ | $O(1)$ (میانگین) | $O(1)$ (میانگین) | $O(1)$ (میانگین) |
| `unordered_map` | ✗ | کلید یکتا | $O(1)$ (میانگین) | $O(1)$ (میانگین) | $O(1)$ (میانگین) |

!!! tip "چه زمانی از کدام استفاده کنیم؟"

    - اگر تنها به آخرین عنصر اضافه‌شده نیاز داریم، از **Stack** استفاده کنید.
    - اگر عناصر باید به ترتیب ورود پردازش شوند، **Queue** انتخاب مناسبی است.
    - اگر درج و حذف از هر دو انتهای دنباله لازم باشد، از **Deque** استفاده کنید.
    - اگر در هر لحظه به کوچک‌ترین یا بزرگ‌ترین عنصر نیاز دارید، از **Priority Queue** استفاده کنید.
    - اگر عناصر باید مرتب باشند، **Set** یا **Map** مناسب هستند.
    - اگر عناصر مرتب باشند و تکرار نیز مجاز باشد، از **Multiset** استفاده کنید.
    - اگر ترتیب عناصر اهمیتی ندارد و سرعت مهم‌تر است، معمولاً **Unordered Set** و **Unordered Map** بهترین انتخاب هستند.
## Iteratorها و پیمایش Containerها

در بسیاری از Containerهای STL مانند `set`، `map`، `multiset` و نسخه‌های `unordered` آن‌ها، دسترسی به عناصر با استفاده از اندیس امکان‌پذیر نیست. در عوض STL از مفهومی به نام **Iterator** استفاده می‌کند. Iterator را می‌توان مشابه یک اشاره‌گر در نظر گرفت که به یکی از عناصر Container اشاره می‌کند و امکان حرکت بین عناصر را فراهم می‌کند.

ابتدای Container با تابع

```cpp
begin()
```

و انتهای آن با

```cpp
end()
```

مشخص می‌شود. توجه کنید که `end()` به عنصر بعد از آخرین عضو اشاره می‌کند و نباید مقدار آن را مستقیماً با `*` خواند.

برای مثال:

```cpp
set<int> st = {2, 5, 8};

auto it = st.begin();

cout << *it;
```

خروجی:

```text
2
```

برای حرکت به عنصر بعدی می‌توان Iterator را افزایش داد.

```cpp
++it;

cout << *it;
```

خروجی:

```text
5
```

یکی از رایج‌ترین کاربردهای Iterator، استفاده از تابع `find` است. این تابع یک Iterator به عنصر موردنظر برمی‌گرداند و اگر عنصر وجود نداشته باشد، مقدار آن برابر `end()` خواهد بود.

```cpp
auto it = st.find(5);

if (it != st.end())
    cout << "Found";
else
    cout << "Not Found";
```

برای پیمایش تمام عناصر یک Container نیز می‌توان از Iterator استفاده کرد.

```cpp
for (auto it = st.begin(); it != st.end(); ++it)
    cout << *it << ' ';
```

که خروجی آن برابر است با:

```text
2 5 8
```

امروزه معمولاً از حلقه‌ی **Range-based For** استفاده می‌شود که همان کار را ساده‌تر انجام می‌دهد.

```cpp
for (int x : st)
    cout << x << ' ';
```

در برخی مسائل نیز لازم است عناصر را از انتها به ابتدا پیمایش کنیم. برای این منظور می‌توان از `rbegin()` و `rend()` استفاده کرد.

```cpp
for (auto it = st.rbegin(); it != st.rend(); ++it)
    cout << *it << ' ';
```

خروجی:

```text
8 5 2
```

!!! note "نکته"

    در اکثر Containerهای STL بهتر است برای تعریف Iterator از کلمه‌ی کلیدی `auto` استفاده شود. این کار علاوه بر کوتاه‌تر شدن کد، خوانایی آن را نیز افزایش می‌دهد.

??? tip "تفاوت `find` و `count`"

    هر دو تابع برای بررسی وجود یک عنصر استفاده می‌شوند، اما رفتار آن‌ها کمی متفاوت است. تابع `count(x)` تنها تعداد دفعات حضور عنصر را برمی‌گرداند که برای `set` و `map` همیشه صفر یا یک است، در حالی که `find(x)` یک Iterator به عنصر موردنظر برمی‌گرداند و در صورت وجود، می‌توان از همان Iterator برای خواندن یا حذف عنصر نیز استفاده کرد.

```cpp
if (st.count(10))
    cout << "Exists";

auto it = st.find(10);

if (it != st.end())
    st.erase(it);
```

## جمع‌بندی

در این فصل با مهم‌ترین ساختمان داده‌های کتابخانه‌ی STL آشنا شدیم و کاربرد، نحوه‌ی استفاده و پیچیدگی زمانی عملیات اصلی هر یک را بررسی کردیم. انتخاب صحیح ساختمان داده، یکی از مهم‌ترین مهارت‌های برنامه‌نویسی مسابقه‌ای است و در بسیاری از مسائل، تفاوت بین یک راه‌حل قابل قبول و یک راه‌حل ناموفق تنها در انتخاب Container مناسب خلاصه می‌شود. در ادامه‌ی شازززگاید، تقریباً در تمام مباحث از این ساختمان داده‌ها استفاده خواهیم کرد؛ بنابراین تسلط بر آن‌ها، یادگیری فصل‌های بعدی را نیز بسیار ساده‌تر خواهد کرد.
