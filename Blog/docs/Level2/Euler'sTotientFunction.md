# تابع فی اویلر

در بسیاری از مسائل نظریه‌ی اعداد نیاز داریم بدانیم چند عدد از $1$ تا $n$ نسبت به $n$ اول هستند. تابعی که این مقدار را می‌دهد، تابع فی اویلر (Euler's Totient Function) نام دارد و با $\phi(n)$ نشان داده می‌شود:

$$\phi(n) = \left|\{\, k \mid 1 \leq k \leq n,\ \gcd(k, n) = 1 \,\}\right|$$

برای مثال اعداد $1, 5, 7, 11$ نسبت به $12$ اول‌اند، پس $\phi(12) = 4$. همچنین برای هر عدد اول $p$ داریم $\phi(p) = p - 1$. این تابع در قضیه‌ی اویلر، توان‌رسانی پیمانه‌ای، رمزنگاری RSA و بسیاری از سوالات مسابقه‌ای کاربرد دارد. در این بخش سه روش برای محاسبه‌ی آن می‌بینیم.

### رابطه با مقسوم‌علیه‌ها

یکی از مهم‌ترین خواص تابع فی رابطه‌ی زیر است:

$$\sum_{d \mid n} \phi(d) = n$$

یعنی اگر مقدار فی تمام مقسوم‌علیه‌های $n$ را جمع کنیم، خود $n$ به دست می‌آید. از این رابطه یک فرمول بازگشتی هم نتیجه می‌شود:

$$\phi(n) = n - \sum_{d \mid n,\ d < n} \phi(d)$$

??? success "اثبات"
    اعداد $1$ تا $n$ را بر اساس مقدار $\gcd(x, n)$ دسته‌بندی می‌کنیم. اگر $\gcd(x, n) = d$ باشد، می‌توان نوشت $x = d \times y$ که در آن $\gcd(y, \frac{n}{d}) = 1$ است. برعکس، هر $y$ بین $1$ تا $\frac{n}{d}$ که نسبت به $\frac{n}{d}$ اول باشد، یک $x = d \times y$ با $\gcd(x, n) = d$ می‌سازد. پس تعداد اعضای دسته‌ی $d$ دقیقا $\phi(\frac{n}{d})$ است.

    هر عدد از $1$ تا $n$ دقیقا در یک دسته قرار می‌گیرد و وقتی $d$ روی مقسوم‌علیه‌های $n$ حرکت می‌کند، $\frac{n}{d}$ هم روی همه‌ی مقسوم‌علیه‌های $n$ حرکت می‌کند. بنابراین:

    $$\sum_{d \mid n} \phi\left(\frac{n}{d}\right) = \sum_{d \mid n} \phi(d) = n$$

#### کد

از رابطه‌ی بازگشتی بالا استفاده می‌کنیم و برای این که مقدار هر عدد چند بار حساب نشود، جواب‌ها را [ممویز](/Level1/recursive/) می‌کنیم.

```cpp linenums="1"

map<int, int> memo;

int phi(int n) {
    if (n == 1)
        return 1;
    if (memo.count(n))
        return memo[n];

    int ans = n;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            int d1 = i, d2 = n / i;
            if (d1 < n)
                ans -= phi(d1);
            if (d2 != d1 && d2 < n)
                ans -= phi(d2);
        }
    }
    return memo[n] = ans;
}
```

#### پیچیدگی زمانی

پیدا کردن مقسوم‌علیه‌های هر عدد $O(\sqrt{n})$ است و این کار را برای هر مقسوم‌علیه $n$ هم انجام می‌دهیم؛ پس زمان این روش حدودا $O(d(n) \sqrt{n})$ است که $d(n)$ تعداد مقسوم‌علیه‌های $n$ است. این روش بیشتر برای درک رابطه‌ی ریاضی مفید است و در عمل از روش‌های بعدی استفاده می‌کنیم.

### فرمول مستقیم با عوامل اول

اگر تجزیه‌ی $n$ به عوامل اول به شکل $n = p_1^{a_1} p_2^{a_2} \dots p_k^{a_k}$ باشد، آنگاه:

$$\phi(n) = n \prod_{i=1}^{k} \left(1 - \frac{1}{p_i}\right)$$

دقت کنید که فقط عوامل اول متمایز اهمیت دارند و توان آن‌ها در فرمول نقشی ندارد. برای مثال $12 = 2^2 \times 3$ است، پس:

$$\phi(12) = 12 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) = 12 \times \frac{1}{2} \times \frac{2}{3} = 4$$

??? success "اثبات"
    ابتدا $n = p^a$ را در نظر بگیرید. اعدادی از $1$ تا $n$ که نسبت به $n$ اول نیستند، دقیقا مضارب $p$ هستند که تعدادشان $\frac{n}{p}$ است. پس:

    $$\phi(p^a) = n - \frac{n}{p} = n \left(1 - \frac{1}{p}\right)$$

    حال اگر $n$ چند عامل اول متمایز داشته باشد، باید اعدادی را حذف کنیم که حداقل بر یکی از این عوامل بخش‌پذیرند. با اصل شمول و عدم شمول می‌توان دید که به ازای هر عامل اول $p$ یک ضریب $(1 - \frac{1}{p})$ ظاهر می‌شود و فرمول بالا به دست می‌آید. (راه دیگر اثبات، استفاده از ضربی بودن تابع فی است: اگر $\gcd(a, b) = 1$ باشد، $\phi(ab) = \phi(a)\phi(b)$.)

به زبان ساده‌تر: به ازای هر عامل اول $p$ از $n$، باید مقدار فعلی جواب را به اندازه‌ی $\frac{1}{p}$ آن کم کنیم.

#### کد

عوامل اول $n$ را مانند [تجزیه‌ی اعداد](/Level2/sieve/) پیدا می‌کنیم و هر بار که عامل اول جدیدی دیدیم، اثر آن را روی جواب اعمال می‌کنیم.

```cpp linenums="1"

int phi(int n) {
    int result = n;
    for (int p = 2; p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) // (1)!
                n /= p;
            result -= result / p; // (2)!
        }
    }
    if (n > 1) // (3)!
        result -= result / n;
    return result;
}
```

1. همه‌ی توان‌های $p$ را از $n$ حذف می‌کنیم تا هر عامل اول فقط یک بار اثر بگذارد.

2. معادل ضرب کردن جواب در $(1 - \frac{1}{p})$ است.

3. اگر در پایان عددی بزرگ‌تر از $1$ باقی ماند، خودش یک عامل اول بزرگ‌تر از $\sqrt{n}$ است.

#### پیچیدگی زمانی

مانند تجزیه‌ی ساده، فقط تا $\sqrt{n}$ پیمایش می‌کنیم و پیچیدگی $O(\sqrt{n})$ است. این رایج‌ترین روش برای محاسبه‌ی فی یک عدد است.

### محاسبه برای همه‌ی اعداد تا $N$

گاهی به جای یک عدد، مقدار $\phi(1), \phi(2), \dots, \phi(N)$ را برای همه‌ی اعداد تا $N$ لازم داریم. اجرای روش قبل برای تک‌تک اعداد $O(N \sqrt{N})$ می‌شود که کند است. به جای آن از ایده‌ی [غربال اراتستن](/Level2/sieve/) استفاده می‌کنیم:

1. ابتدا برای هر $i$ قرار می‌دهیم $\phi(i) = i$.
2. اعداد را از کوچک به بزرگ می‌بینیم. اگر $\phi(p) = p$ هنوز تغییر نکرده باشد، یعنی $p$ اول است.
3. برای هر عدد اول $p$، روی همه‌ی مضارب آن مانند $j$ حرکت می‌کنیم و قرار می‌دهیم $\phi(j) = \phi(j) - \frac{\phi(j)}{p}$.

مرحله‌ی سوم دقیقا همان اعمال ضریب $(1 - \frac{1}{p})$ در فرمول مستقیم است و چون هر عامل اول $j$ دقیقا یک بار به آن می‌رسد، در پایان $\phi(j)$ درست محاسبه شده است.

#### کد

```cpp linenums="1"

vector<int> phiSieve(int n) {
    vector<int> phi(n + 1);
    for (int i = 0; i <= n; i++)
        phi[i] = i;

    for (int p = 2; p <= n; p++) {
        if (phi[p] == p) { // (1)!
            for (int j = p; j <= n; j += p)
                phi[j] -= phi[j] / p;
        }
    }
    return phi;
}
```

1. اگر تا این‌جا هیچ عامل اول کوچک‌تری به $p$ نرسیده باشد، $p$ خودش اول است.

#### پیچیدگی زمانی

درست مانند غربال اراتستن، تعداد عملیات‌ها برابر $\frac{N}{2} + \frac{N}{3} + \frac{N}{5} + \dots$ روی اعداد اول است که از $O(N \log \log N)$ است.

!!! tip "نکته"
    اگر فقط مقدار فی یک عدد را می‌خواهیم، روش $O(\sqrt{n})$ مناسب‌تر است؛ اما اگر مقدار فی اعداد زیادی تا یک کران مشخص لازم است، غربال انتخاب بهتری است.

### کاربرد ها

#### قضیه‌ی اویلر

معروف‌ترین کاربرد تابع فی، قضیه‌ی اویلر است که تعمیم [قضیه‌ی کوچک فرما](/Level2/fermat/) به پیمانه‌های غیر اول است. اگر $\gcd(a, n) = 1$ باشد:

$$a^{\phi(n)} \equiv 1 \pmod{n}$$

از این قضیه برای کوچک کردن توان‌های خیلی بزرگ در محاسبات پیمانه‌ای و همچنین پیدا کردن وارون ضربی به پیمانه‌ی غیر اول ($a^{-1} \equiv a^{\phi(n) - 1}$) استفاده می‌شود.
