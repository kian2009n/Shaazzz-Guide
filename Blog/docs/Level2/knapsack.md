# knapsack dp (سوال کوله پشتی)

## توضیحات 
در مسئله‌ی کوله‌پشتی (Knapsack) یک کوله‌پشتی با حجم مشخص و تعدادی وسیله داریم که حجم هر کدام داده شده است. می‌خواهیم تعدادی از وسیله‌ها را طوری در کوله‌پشتی بگذاریم که بیشترین فضای ممکن از آن پر شود. (فرض کنید شکل وسیله‌ها طوری است که فضای خالی بین آن‌ها نمی‌ماند.) این مسئله یکی از کلاسیک‌ترین مثال‌های [برنامه‌نویسی پویا](/Level2/dp/) است و الگوی حل آن در سوالات زیادی تکرار می‌شود.

### مسئله

$n$ وسیله داریم که حجم وسیله‌ی $i$ام برابر $a_i$ است و حجم کوله‌پشتی $w$ است. بیشترین حجمی که می‌توان از کوله‌پشتی پر کرد چقدر است؟ می‌خواهیم مسئله را در $O(n \times w)$ حل کنیم.

### راه حل

آرایه‌ی دوبعدی $dp$ به ابعاد $(n+1) \times (w+1)$ تعریف می‌کنیم و می‌گوییم $dp_{i, j}$ برابر یک است اگر بتوان با استفاده از $i$ وسیله‌ی اول دقیقا حجم $j$ را پر کرد؛ یعنی زیرمجموعه‌ای از $i$ وسیله‌ی اول وجود داشته باشد که مجموع حجمشان $j$ باشد. در غیر این صورت $dp_{i, j}$ صفر است. جواب مسئله بزرگ‌ترین $j$ است که $dp_{n, j}$ یک باشد.

**پایه:** با صفر وسیله فقط می‌توان حجم صفر را ساخت؛ پس $dp_{0, 0} = 1$ و بقیه‌ی خانه‌های سطر صفر برابر صفرند.

**رابطه‌ی بازگشتی:** برای محاسبه‌ی $dp_{i, j}$ دو حالت داریم:

1. از وسیله‌ی $i$ام استفاده نشده است. در این حالت باید بتوان با $i-1$ وسیله‌ی اول حجم $j$ را پر کرد، یعنی $dp_{i-1, j} = 1$.
2. از وسیله‌ی $i$ام استفاده شده است. در این حالت باید $a_i \leq j$ باشد و بتوان با $i-1$ وسیله‌ی اول حجم $j - a_i$ را پر کرد، یعنی $dp_{i-1, j-a_i} = 1$.

اگر حداقل یکی از دو حالت برقرار باشد $dp_{i, j} = 1$ و در غیر این صورت $dp_{i, j} = 0$ است.

### کد

```cpp linenums="1"

bool dp[N][W];
int a[N];

int main() {
    int n, w; cin >> n >> w;
    for (int i = 1; i <= n; i++) cin >> a[i];

    dp[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= w; j++) {
            dp[i][j] = dp[i - 1][j]; // (1)!
            if (j >= a[i] && dp[i - 1][j - a[i]]) dp[i][j] = 1; // (2)!
        }
    }

    int ans = 0;
    for (int j = 1; j <= w; j++) if (dp[n][j]) ans = j;
    cout << ans << endl;
}
```

1. حالت اول: وسیله‌ی $i$ام را برنمی‌داریم.

2. حالت دوم: وسیله‌ی $i$ام را برمی‌داریم.

### پیچیدگی زمانی

هر خانه‌ی جدول در $O(1)$ پر می‌شود، پس زمان و حافظه هر دو از $O(n \times w)$ هستند.

### بهینه‌سازی حافظه

اگر دقت کنید، برای پر کردن سطر $i$ام فقط به سطر $i-1$ام نیاز داریم. پس اگر سطرها را به ترتیب پر کنیم، نگه داشتن کل جدول بی‌فایده است و دو سطر کافی است. با این کار حافظه به $O(w)$ کاهش پیدا می‌کند. برای این کار کافی است به جای اندیس $i$ از $i \bmod 2$ استفاده کنیم.

```cpp linenums="1" hl_lines="11 12 17"

bool dp[2][W];
int a[N];

int main() {
    int n, w; cin >> n >> w;
    for (int i = 1; i <= n; i++) cin >> a[i];

    dp[0][0] = 1;
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= w; j++) {
            dp[i % 2][j] = dp[(i - 1) % 2][j];
            if (j >= a[i] && dp[(i - 1) % 2][j - a[i]]) dp[i % 2][j] = 1;
        }
    }

    int ans = 0;
    for (int j = 1; j <= w; j++) if (dp[n % 2][j]) ans = j;
    cout << ans << endl;
}
```

### کوله‌پشتی با ارزش

حالا فرض کنید هر وسیله علاوه بر حجم $a_i$، ارزش $b_i$ هم دارد و می‌خواهیم وسایلی را برداریم که در کوله‌پشتی جا شوند و مجموع ارزش آن‌ها بیشینه باشد. سعی کنید این حالت را هم در $O(n \times w)$ حل کنید.

??? success "راه حل"
    حل این حالت خیلی شبیه حالت قبل است. این بار $dp_{i, j}$ را برابر بیشترین ارزشی تعریف می‌کنیم که می‌توان با $i$ وسیله‌ی اول و کوله‌پشتی‌ای به حجم $j$ به دست آورد. جواب مسئله $dp_{n, w}$ است.

    **پایه:** با صفر وسیله هیچ ارزشی به دست نمی‌آید، پس $dp_{0, j} = 0$.

    **رابطه‌ی بازگشتی:** باز هم دو حالت داریم:

    1. وسیله‌ی $i$ام را برنمی‌داریم: بهترین جواب با $i-1$ وسیله‌ی اول و حجم $j$، یعنی $dp_{i-1, j}$.
    2. وسیله‌ی $i$ام را برمی‌داریم (به شرط $a_i \leq j$): ارزش $b_i$ را می‌گیریم و بقیه‌ی حجم یعنی $j - a_i$ را با $i-1$ وسیله‌ی اول به بهترین شکل پر می‌کنیم، یعنی $b_i + dp_{i-1, j-a_i}$.

    مقدار $dp_{i, j}$ بیشینه‌ی این دو حالت است. مانند قبل، نگه داشتن دو سطر از جدول کافی است.

    ```cpp linenums="1"

    int dp[2][W];
    int a[N], b[N];

    int main() {
        int n, w; cin >> n >> w;
        for (int i = 1; i <= n; i++) cin >> a[i];
        for (int i = 1; i <= n; i++) cin >> b[i];

        for (int i = 1; i <= n; i++) {
            for (int j = 0; j <= w; j++) {
                dp[i % 2][j] = dp[(i - 1) % 2][j];
                if (j >= a[i])
                    dp[i % 2][j] = max(dp[i % 2][j], b[i] + dp[(i - 1) % 2][j - a[i]]);
            }
        }

        cout << dp[n % 2][w] << endl;
    }
    ```

    پیچیدگی زمانی $O(n \times w)$ و حافظه $O(w)$ است.

!!! tip "نکته"
    حالت اول در واقع همین مسئله با $b_i = a_i$ است: بیشترین ارزش همان بیشترین حجم پرشده می‌شود.

### آرایه‌ی یک‌بعدی

روش $i \bmod 2$ کار می‌کند، اما در عمل روش رایج‌تر این است که فقط یک سطر نگه داریم و آن را «در جا» به‌روز کنیم. فرض کنید $dp_j$ همان سطر $i-1$ است و می‌خواهیم آن را به سطر $i$ تبدیل کنیم. رابطه‌ی $dp_{i, j} = \max(dp_{i-1, j},\ b_i + dp_{i-1, j-a_i})$ به خانه‌ی $j - a_i$ از سطر **قبل** نیاز دارد. اگر $j$ را از بزرگ به کوچک طی کنیم، وقتی به $j$ می‌رسیم خانه‌ی $j - a_i$ هنوز به‌روز نشده و مقدار سطر قبل را دارد؛ دقیقا همان چیزی که می‌خواهیم.

```cpp linenums="1"

int dp[W];
int a[N], b[N];

int main() {
    int n, w; cin >> n >> w;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    for (int i = 1; i <= n; i++)
        for (int j = w; j >= a[i]; j--) // (1)!
            dp[j] = max(dp[j], b[i] + dp[j - a[i]]);

    cout << dp[w] << endl;
}
```

1. حلقه‌ی $j$ باید نزولی باشد. چون $j$ از $a_i$ شروع می‌شود و پایین‌تر نمی‌رود، شرط $j \geq a_i$ هم خودبه‌خود رعایت شده و حالت «برنداشتن» هم همان مقدار قبلی $dp_j$ است.

!!! danger "مهم"
    اگر حلقه‌ی $j$ را صعودی بنویسید، خانه‌ی $j - a_i$ قبل از $j$ به‌روز می‌شود و ممکن است خودش شامل وسیله‌ی $i$ باشد؛ یعنی یک وسیله را چند بار برمی‌دارید. این اشتباه رایج، جواب را به مسئله‌ی بخش بعد تبدیل می‌کند!

### کوله‌پشتی نامحدود

حالا فرض کنید از هر وسیله بی‌نهایت نسخه داریم و می‌توانیم هر کدام را چند بار برداریم. به این حالت کوله‌پشتی نامحدود (Unbounded Knapsack) می‌گویند. رابطه‌ی بازگشتی تغییر کوچکی می‌کند: وقتی وسیله‌ی $i$ام را برمی‌داریم، همچنان اجازه داریم دوباره از آن استفاده کنیم، پس به جای $dp_{i-1, j-a_i}$ باید از $dp_{i, j-a_i}$ استفاده کنیم:

$$dp_{i, j} = \max(dp_{i-1, j},\ b_i + dp_{i, j-a_i})$$

در نسخه‌ی یک‌بعدی این یعنی دقیقا همان کدی که در پنل بالا به عنوان اشتباه معرفی شد: کافی است حلقه‌ی $j$ را صعودی بنویسیم، چون این بار **می‌خواهیم** خانه‌ی $j - a_i$ قبلا با وسیله‌ی $i$ به‌روز شده باشد.

```cpp linenums="1" hl_lines="2"

for (int i = 1; i <= n; i++)
    for (int j = a[i]; j <= w; j++)
        dp[j] = max(dp[j], b[i] + dp[j - a[i]]);
```

!!! tip "نکته"
    جهت حلقه‌ی $j$ همه‌ی تفاوت دو مسئله است: نزولی یعنی هر وسیله حداکثر یک بار، صعودی یعنی هر وسیله هر چند بار. مسئله‌ی معروف «کمترین تعداد سکه برای ساختن مبلغ $w$» همین کوله‌پشتی نامحدود است که در آن به جای بیشینه، کمینه می‌گیریم.

### بازسازی جواب

تا این‌جا فقط مقدار بهینه را حساب کردیم. اگر بخواهیم بدانیم دقیقا کدام وسیله‌ها برداشته شده‌اند، باید جدول کامل دوبعدی را نگه داریم و از خانه‌ی جواب به عقب برگردیم. از $(i, j) = (n, w)$ شروع می‌کنیم و در هر مرحله بررسی می‌کنیم $dp_{i, j}$ از کدام حالت به دست آمده است:

+ اگر $dp_{i, j} = dp_{i-1, j}$ باشد، وسیله‌ی $i$ لازم نبوده؛ به $(i-1, j)$ می‌رویم.
+ در غیر این صورت وسیله‌ی $i$ برداشته شده؛ آن را به جواب اضافه می‌کنیم و به $(i-1, j - a_i)$ می‌رویم.

```cpp linenums="1"

vector<int> chosen;
int j = w;
for (int i = n; i >= 1; i--) {
    if (dp[i][j] != dp[i - 1][j]) { // (1)!
        chosen.push_back(i);
        j -= a[i];
    }
}
```

1. اگر مقدار با سطر قبل فرق دارد، تنها راه رسیدن به آن برداشتن وسیله‌ی $i$ بوده است.

این کار $O(n)$ زمان می‌برد، اما چون به کل جدول نیاز دارد، حافظه به $O(n \times w)$ برمی‌گردد و دیگر نمی‌توان از آرایه‌ی یک‌بعدی استفاده کرد.

### کاربرد: زیرمجموعه با مجموع مشخص

خیلی از سوالات ظاهرا ربطی به کوله‌پشتی ندارند، اما دقیقا همین هستند. معروف‌ترین آن‌ها مسئله‌ی مجموع زیرمجموعه (Subset Sum) است: آیا زیرمجموعه‌ای از اعداد $a_1, \dots, a_n$ وجود دارد که مجموعش دقیقا $s$ باشد؟ این همان مسئله‌ی اول این بخش است و $dp_{n, s}$ جواب آن است.

??? success "مثال: تقسیم به دو گروه با مجموع برابر"
    می‌خواهیم اعداد را به دو گروه با مجموع برابر تقسیم کنیم. اگر مجموع کل $S$ فرد باشد، جواب منفی است. در غیر این صورت کافی است بررسی کنیم زیرمجموعه‌ای با مجموع $\frac{S}{2}$ وجود دارد یا نه، چون بقیه‌ی اعداد خودبه‌خود مجموع $\frac{S}{2}$ خواهند داشت. پس جواب همان $dp_{n, S/2}$ است و در $O(n \times S)$ به دست می‌آید.

??? success "مثال: شمردن زیرمجموعه‌ها"
    اگر به جای «وجود دارد یا نه» بخواهیم **تعداد** زیرمجموعه‌هایی با مجموع $j$ را بشماریم، کافی است $dp$ را عدد صحیح تعریف کنیم و به جای «یا» دو حالت را با هم جمع کنیم:

    $$dp_{i, j} = dp_{i-1, j} + dp_{i-1, j-a_i}$$

    چون تعداد زیرمجموعه‌ها خیلی بزرگ می‌شود، معمولا جواب را به پیمانه‌ی عددی مانند $10^9 + 7$ می‌خواهند.

    ```cpp linenums="1"

    long long dp[W];
    const long long mod = 1e9 + 7;

    dp[0] = 1;
    for (int i = 1; i <= n; i++)
        for (int j = w; j >= a[i]; j--)
            dp[j] = (dp[j] + dp[j - a[i]]) % mod;
    ```
