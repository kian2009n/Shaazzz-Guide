در بسیاری از مسائل، مخصوصا مسائل شمارشی، نیاز داریم توان یک عدد را سریع حساب کنیم. در این بخش الگوریتمی ارائه می‌دهیم که $a^x$ را در $O(\log x)$ محاسبه می‌کند. معمولا چون این عدد خیلی بزرگ می‌شود، باقی‌مانده‌ی آن را بر یک عدد ثابت مانند $mod$ می‌خواهند.

### راه حل ساده

ساده‌ترین راه برای محاسبه‌ی $a^x$ این است که $x$ بار ضرب انجام دهیم و بعد از هر ضرب، باقی‌مانده را بر $mod$ بگیریم.

```cpp linenums="1"

long long a, x, mod = 1e9 + 7;

int main() {
    cin >> a >> x;

    long long res = 1;
    for (long long i = 1; i <= x; i++) {
        res *= a;
        res %= mod;
    }

    cout << res << endl;
}
```

پیچیدگی زمانی این روش $O(x)$ است که برای $x$های بزرگ (مثلا $10^{18}$) اصلا قابل استفاده نیست.

### مسئله

می‌خواهیم باقی‌مانده‌ی $a^x$ بر $mod$ را در $O(\log x)$ حساب کنیم.

### راه حل

فرض کنید $x$ زوج است و جواب را برای $a^{x/2}$ می‌دانیم و آن را $r$ می‌نامیم. در این صورت $a^x = r^2$ است. اگر $x$ فرد باشد و $r = a^{(x-1)/2}$ را بدانیم، جواب برابر $r^2 \times a$ است. پس می‌توانیم $a^x$ را به صورت [بازگشتی](/Level1/recursive/) حساب کنیم و در هر مرحله توان نصف می‌شود. به این روش توان دودویی (Binary Exponentiation) می‌گویند.

### کد

```cpp linenums="1"

long long A, X, mod = 1e9 + 7;

long long poww(long long a, long long x) {
    if (x == 0) return 1;

    long long r = poww((a * a) % mod, x / 2); // (1)!

    if (x % 2 == 1) return (r * a) % mod;
    return r;
}

int main() {
    cin >> A >> X;
    cout << poww(A % mod, X) << endl; // (2)!
}
```

1. چون خود $a$ را به توان ۲ رساندیم، دیگر نیازی به محاسبه‌ی $r \times r$ نیست. همچنین `#!cpp x / 2` در <span dir="ltr">C++</span> خودبه‌خود کف تقسیم را حساب می‌کند.

2. قبل از شروع، $a$ را به پیمانه‌ی $mod$ می‌بریم؛ اگر $a$ خودش بزرگ باشد (مثلا تا $10^{18}$)، حاصل $a \times a$ در `#!cpp long long` جا نمی‌شود. اگر $a$ ممکن است منفی باشد، به جای آن `#!cpp (A % mod + mod) % mod` بنویسید.

### روش غیربازگشتی

می‌دانیم $a^{x+y} = a^x \times a^y$. پس می‌توانیم $x$ را در [مبنای ۲](/Level1/bitmask/) بنویسیم و به ازای هر بیت $i$ که در $x$ برابر ۱ است، مقدار $a^{2^i}$ را در جواب ضرب کنیم. مقدار $a^{2^i}$ هم به سادگی از $a^{2^{i-1}}$ به دست می‌آید:

$$a^{2^i} = a^{2^{i-1}} \times a^{2^{i-1}}$$

```cpp linenums="1"

long long A, X, mod = 1e9 + 7;

long long poww(long long a, long long x) {
    a %= mod; // (3)!
    long long result = 1;
    while (x > 0) {
        if (x % 2 == 1) { // (1)!
            result = (result * a) % mod;
        }
        a = (a * a) % mod; // (2)!
        x /= 2;
    }
    return result;
}

int main() {
    cin >> A >> X;
    cout << poww(A, X) << endl;
}
```

1. بررسی می‌کنیم که بیت فعلی $x$ برابر ۱ است یا خیر.

2. در این خط $a$ از $a^{2^i}$ به $a^{2^{i+1}}$ تبدیل می‌شود.

3. همان کوچک کردن $a$ قبل از شروع، این بار داخل خود تابع.

!!! warning ""
    حاصل ضرب دو عدد کوچک‌تر از $10^9 + 7$ در `#!cpp int` جا نمی‌شود؛ حتما از `#!cpp long long` استفاده کنید.

!!! tip "کوچک کردن توان"
    اگر $mod$ عددی اول مانند $p$ باشد و $a$ بر $p$ بخش‌پذیر نباشد، طبق [قضیه‌ی کوچک فرما](/Level2/fermat/) داریم $a^{p-1} \equiv 1 \pmod p$. پس توان‌ها به پیمانه‌ی $p - 1$ تکرار می‌شوند و می‌توان نوشت

    $$a^x \equiv a^{x \bmod (p-1)} \pmod p$$

    این نکته وقتی به کار می‌آید که خود $x$ در `#!cpp long long` جا نشود؛ مثلا $x$ یک عدد خیلی بزرگ به صورت رشته باشد یا خودش حاصل یک توان مانند $b^c$ باشد. در این حالت کافی است $x$ را به پیمانه‌ی $p - 1$ حساب کنیم (نه $p$!) و سپس توان دودویی را اجرا کنیم.

### کاربرد ها

خیلی وقت‌ها نیاز داریم به کمک [قضیه‌ی کوچک فرما](/Level2/fermat/) یک تقسیم را به پیمانه‌ی $mod$ انجام دهیم. مثلا برای به دست آوردن $\frac{1}{a}$ به پیمانه‌ی $mod$ باید $a^{mod-2}$ را حساب کنیم که اگر $mod$ بزرگ باشد، به الگوریتمی سریع‌تر از $O(mod)$ نیاز داریم و دقیقا همین روش به کار می‌آید. همچنین از همین ایده برای به توان رساندن ماتریس‌ها هم استفاده می‌شود.
