مقسوم‌علیه‌های یک عدد، اعدادی هستند که آن عدد بر آن‌ها بخش‌پذیر است. برای مثال مقسوم‌علیه‌های $12$ عبارت‌اند از $1, 2, 3, 4, 6, 12$ و در نتیجه $12$ شش مقسوم‌علیه دارد. همچنین به عددی بزرگ‌تر از ۱ که دقیقا دو مقسوم‌علیه ($1$ و خودش) داشته باشد، عدد اول می‌گوییم. در این بخش می‌خواهیم یاد بگیریم تعداد مقسوم‌علیه‌های یک عدد را بشماریم و اول بودن یک عدد را تشخیص دهیم.

### مسئله

عدد طبیعی $n$ داده شده است. می‌خواهیم دو تابع بنویسیم:

1. تابعی که تعداد مقسوم‌علیه‌های $n$ را حساب کند.
2. تابعی که مشخص کند $n$ اول است یا نه.

### راه حل ساده

ساده‌ترین کار این است که روی تمام اعداد $1$ تا $n$ حرکت کنیم و به ازای هر $i$ بررسی کنیم که آیا $n$ بر $i$ بخش‌پذیر است یا خیر. این روش از $O(n)$ زمان می‌برد و برای $n$های بزرگ (مثلا $10^9$) بسیار کند است.

### راه حل بهتر

نکته‌ی اصلی این است که اگر $d$ یک مقسوم‌علیه $n$ باشد، آنگاه $\frac{n}{d}$ هم یک مقسوم‌علیه $n$ است. بنابراین از هر جفت $(d, \frac{n}{d})$ حداقل یکی کوچک‌تر یا مساوی $\sqrt{n}$ است و کافی است فقط تا $\sqrt{n}$ پیمایش کنیم:

+ اگر $i$ مقسوم‌علیه $n$ باشد و $i \neq \frac{n}{i}$، دو مقسوم‌علیه $i$ و $\frac{n}{i}$ را می‌شماریم.
+ اگر $i = \frac{n}{i}$ باشد (یعنی $n = i^2$)، فقط یک مقسوم‌علیه می‌شماریم.

به این ترتیب پیچیدگی زمانی به $O(\sqrt{n})$ کاهش پیدا می‌کند.

### کد

```cpp linenums="1"

long long countDivisors(long long n) { // (1)!
    long long cnt = 0;
    for (long long i = 1; i * i <= n; i++) { // (2)!
        if (n % i == 0) {
            if (i * i == n) cnt++; // (3)!
            else cnt += 2;
        }
    }
    return cnt;
}
```

1. چون $n$ می‌تواند تا حدود $10^{12}$ باشد و $i \times i$ هم به همان اندازه بزرگ می‌شود، از `#!cpp long long` استفاده می‌کنیم؛ با `#!cpp int` حاصل $i \times i$ سرریز می‌کند.

2. به جای `#!cpp i <= sqrt(n)` از `#!cpp i * i <= n` استفاده می‌کنیم تا با خطای اعشاری روبه‌رو نشویم.

3. در این حالت $i$ و $\frac{n}{i}$ یکی هستند و نباید دو بار شمرده شوند.

### تشخیص اول بودن

عدد اول دقیقا ۲ مقسوم‌علیه دارد، پس می‌توانستیم از همان تابع بالا استفاده کنیم. اما راه مستقیم‌تر این است که به دنبال یک مقسوم‌علیه بین $2$ تا $\sqrt{n}$ بگردیم؛ اگر چنین عددی پیدا نشد، $n$ اول است.

```cpp linenums="1"

bool isPrime(long long n) {
    if (n < 2) return false; // (1)!
    for (long long i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}
```

1. دقت کنید که $1$ تنها یک مقسوم‌علیه دارد و اول نیست.

!!! warning ""
    روش $O(\sqrt{n})$ برای اعداد تا حدود $10^{12}$ کاملا مناسب است. برای اعداد خیلی بزرگ‌تر (مثلا $10^{18}$) به الگوریتم‌های پیشرفته‌تری مانند آزمون میلر-رابین (Miller-Rabin) نیاز داریم که در سطوح بعدی به آن می‌پردازیم.
