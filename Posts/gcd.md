بزرگ‌ترین مقسوم‌علیه مشترک (GCD) دو عدد $A$ و $B$، بزرگ‌ترین عددی است که هر دوی آن‌ها بر آن بخش‌پذیر باشند و آن را با $\gcd(A, B)$ نشان می‌دهیم. الگوریتم اقلیدس یکی از قدیمی‌ترین و ساده‌ترین روش‌ها برای پیدا کردن ب.م.م دو عدد است که در این بخش با آن آشنا می‌شویم.

### الگوریتم اقلیدس

فرض کنید دو عدد $A$ و $B$ داده شده‌اند و بدون کاستن از کلیت مسئله $A \geq B$ است. ایده‌ی اصلی این است که ب.م.م $A$ و $B$ با ب.م.م $B$ و باقی‌مانده‌ی تقسیم $A$ بر $B$ برابر است:

$$\gcd(A, B) = \gcd(B, A \bmod B)$$

این کار را آن‌قدر ادامه می‌دهیم تا یکی از دو عدد صفر شود. در این لحظه عدد دیگر همان ب.م.م است، چون $\gcd(x, 0) = x$.

??? success "اثبات"
    اگر $A = qB + r$ باشد، هر عددی که $A$ و $B$ را بشمارد، $r = A - qB$ را هم می‌شمارد و هر عددی که $B$ و $r$ را بشمارد، $A = qB + r$ را هم می‌شمارد. پس مجموعه‌ی مقسوم‌علیه‌های مشترک $(A, B)$ و $(B, r)$ یکی است و در نتیجه بزرگ‌ترین عضو این دو مجموعه هم یکی است.

### کد

الگوریتم را می‌توان هم به صورت بازگشتی و هم غیربازگشتی پیاده کرد.

#### روش بازگشتی

```cpp linenums="1"

int gcd(int a, int b) {
    if (b == 0)
        return a;
    return gcd(b, a % b);
}
```

#### روش غیربازگشتی

```cpp linenums="1"

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}
```

#### تابع آماده‌ی <span dir="ltr">C++</span>

خود <span dir="ltr">C++</span> تابع `#!cpp __gcd` را دارد که همین کار را انجام می‌دهد (در نسخه‌های جدیدتر <span dir="ltr">C++</span> تابع استاندارد `#!cpp gcd` هم وجود دارد).

```cpp linenums="1"

int main() {
    int A, B;
    cin >> A >> B;
    cout << __gcd(A, B) << endl;
}
```

### پیچیدگی زمانی

پیچیدگی زمانی الگوریتم اقلیدس $O(\log(\min(A, B)))$ است. دلیل آن این است که در هر دو مرحله، عدد بزرگ‌تر حداقل نصف می‌شود.

??? success "اثبات"
    فرض کنید $B \leq A$ باشد (اگر این‌طور نباشد، بعد از یک مرحله جای دو عدد عوض می‌شود). می‌خواهیم نشان دهیم $A \bmod B \leq \frac{A}{2}$ است. دو حالت داریم:

    1. اگر $A \geq 2B$ باشد، چون باقی‌مانده همیشه از $B$ کوچک‌تر است، داریم $A \bmod B < B \leq \frac{A}{2}$.
    2. اگر $A < 2B$ باشد، باقی‌مانده برابر $A - B$ است و چون $B > \frac{A}{2}$، داریم $A - B < \frac{A}{2}$.

    پس بعد از هر دو مرحله، عدد بزرگ‌تر حداقل نصف می‌شود و تعداد مراحل از $O(\log(\min(A, B)))$ است.

### کاربرد ها

#### کوچک‌ترین مضرب مشترک

با داشتن ب.م.م، می‌توان کوچک‌ترین مضرب مشترک (LCM) دو عدد را هم به دست آورد:

$$\text{lcm}(A, B) = \frac{A \times B}{\gcd(A, B)}$$

!!! warning ""
    برای جلوگیری از سرریز (overflow)، بهتر است ابتدا $A$ را بر $\gcd(A, B)$ تقسیم کنید و سپس در $B$ ضرب کنید.

#### مثال

برای $A = 48$ و $B = 18$ مراحل الگوریتم به شکل زیر است:

1. $48 \bmod 18 = 12$
2. $18 \bmod 12 = 6$
3. $12 \bmod 6 = 0$

پس $\gcd(48, 18) = 6$. به همین ترتیب برای $A = 103$ و $B = 101$:

1. $103 \bmod 101 = 2$
2. $101 \bmod 2 = 1$
3. $2 \bmod 1 = 0$

پس $\gcd(103, 101) = 1$؛ یعنی این دو عدد نسبت به هم اول‌اند.
