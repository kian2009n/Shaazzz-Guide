در بسیاری از مسائل، دانستن الگوریتم به تنهایی کافی نیست و انتخاب داده‌ساختار (Data Structure) مناسب هم در سرعت اجرا و هم در سادگی پیاده‌سازی نقش مهمی دارد. داده‌ساختار روشی برای ذخیره و سازمان‌دهی داده‌هاست به طوری که عملیات‌هایی مثل درج، حذف، جستجو و دسترسی به اعضا سریع انجام شوند. دو کد ممکن است ایده‌ی یکسانی داشته باشند، اما یکی به خاطر انتخاب داده‌ساختار درست در زمان مجاز اجرا شود و دیگری با خطای زمان (Time Limit) مواجه شود. در این بخش با پرکاربردترین داده‌ساختارهای کتابخانه‌ی استاندارد <span dir="ltr">C++ (STL)</span> آشنا می‌شویم. برای استفاده از همه‌ی آن‌ها کافی است <span dir="ltr">`#!cpp #include <bits/stdc++.h>`</span> را در ابتدای کد بنویسید.

### وکتور (Vector) و زوج (Pair)

پرکاربردترین داده‌ساختار STL وکتور است: آرایه‌ای که اندازه‌اش می‌تواند در حین اجرا تغییر کند. در [سطح ۱](/Level1/implementation/) با آن کار کرده‌اید، اما چون بقیه‌ی این بخش بارها به آن برمی‌گردد، مهم‌ترین توابع آن را یک جا مرور می‌کنیم.

| تابع | توضیح |
|------|-------|
| `push_back(x)` | اضافه کردن $x$ به انتها |
| `pop_back()` | حذف عضو آخر |
| `back()` / `front()` | دیدن عضو آخر / اول |
| `size()` / `empty()` | تعداد اعضا / خالی بودن |
| `resize(n)` | تغییر اندازه به $n$ |
| `clear()` | حذف همه‌ی اعضا |

```cpp linenums="1"

vector<int> v = {5, 1, 4};

v.push_back(3); // 5 1 4 3
v.pop_back();   // 5 1 4

sort(v.begin(), v.end()); // 1 4 5

int idx = lower_bound(v.begin(), v.end(), 4) - v.begin(); // (1)!
cout << idx << endl; // 1

vector<vector<int>> g(n); // (2)!
g[0].push_back(1);
```

1. روی وکتور مرتب‌شده می‌توان با `#!cpp lower_bound` و `#!cpp upper_bound` [جستجوی دودویی](/Level1/binary_search/) انجام داد. این توابع ایتریتور برمی‌گردانند و با کم کردن `#!cpp v.begin()` به اندیس تبدیل می‌شوند.

2. وکتوری از وکتورها، ساده‌ترین راه ساختن آرایه‌ی دوبعدی با سطرهایی با طول متفاوت است؛ مثلا برای نگه داشتن [لیست مجاورت گراف](/Level2/dfs/).

دسترسی با اندیس، `#!cpp push_back` و `#!cpp pop_back` از $O(1)$ هستند. اما درج یا حذف از وسط وکتور (`#!cpp insert` و `#!cpp erase`) نیاز به جابه‌جا کردن اعضای بعدی دارد و $O(n)$ است.

!!! warning ""
    دسترسی به اندیسی خارج از بازه‌ی وکتور (مثلا `#!cpp v[v.size()]`) خطا نمی‌دهد، اما رفتار برنامه نامشخص می‌شود و معمولا به جواب اشتباه یا Runtime Error می‌انجامد. همچنین `#!cpp v.size()` از نوع بدون علامت است؛ عبارت `#!cpp v.size() - 1` وقتی وکتور خالی است عددی بسیار بزرگ می‌شود، پس بهتر است آن را به `#!cpp int` تبدیل کنید.

#### زوج (Pair)

زوج دو مقدار (حتی از دو نوع متفاوت) را کنار هم نگه می‌دارد که با `#!cpp first` و `#!cpp second` به آن‌ها دسترسی داریم. زوج‌ها ابتدا بر اساس `#!cpp first` و در صورت تساوی بر اساس `#!cpp second` مقایسه می‌شوند؛ به همین دلیل می‌توان وکتوری از زوج‌ها را مستقیم مرتب کرد یا آن‌ها را در `#!cpp set` و `#!cpp priority_queue` ریخت.

```cpp linenums="1"

vector<pair<int, int>> a;

a.push_back({3, 1});
a.push_back({1, 7});
a.push_back({3, 0});

sort(a.begin(), a.end()); // (1, 7) (3, 0) (3, 1)

for (auto [x, y] : a) // (1)!
    cout << x << ' ' << y << endl;
```

1. با این نوشتار (Structured Binding) دو عضو زوج مستقیم در `#!cpp x` و `#!cpp y` قرار می‌گیرند. معادل `#!cpp p.first` و `#!cpp p.second` است.

### استک (Stack)

استک یا پشته ساده‌ترین داده‌ساختار این بخش است و از قانون «آخرین ورودی، اولین خروجی» (LIFO) پیروی می‌کند؛ یعنی آخرین عضوی که وارد شده، اولین عضوی است که خارج می‌شود. می‌توانید استک را مثل دسته‌ای بشقاب تصور کنید که هر بشقاب جدید روی دسته گذاشته می‌شود و همیشه بشقاب بالایی برداشته می‌شود. استک در پیاده‌سازی [DFS](/Level2/dfs/)، بررسی درستی پرانتزها، محاسبه‌ی عبارات ریاضی و خیلی از الگوریتم‌های دیگر به کار می‌رود.

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن $x$ به بالای استک |
| `pop()` | حذف عضو بالایی |
| `top()` | دیدن عضو بالایی |
| `empty()` | آیا استک خالی است؟ |
| `size()` | تعداد اعضا |

```cpp linenums="1"

stack<int> st;

st.push(10);
st.push(20);
st.push(30);

cout << st.top() << endl; // 30
st.pop();
cout << st.top() << endl; // 20
```

همه‌ی این عملیات‌ها از $O(1)$ هستند.

!!! warning ""
    در استک فقط به عضو بالایی دسترسی داریم. اگر به پیمایش اعضا یا دسترسی با اندیس نیاز دارید، از `#!cpp vector` استفاده کنید؛ `#!cpp push_back`، `#!cpp pop_back` و `#!cpp back` در `#!cpp vector` دقیقا همان کار استک را می‌کنند و به همین دلیل خیلی‌ها در مسابقات به جای `#!cpp stack` از `#!cpp vector` استفاده می‌کنند.

### صف (Queue)

صف از قانون «اولین ورودی، اولین خروجی» (FIFO) پیروی می‌کند؛ درست مثل صف بانک، هر نفر جدید به انتهای صف می‌رود و همیشه از ابتدای صف خدمت داده می‌شود. معروف‌ترین کاربرد صف الگوریتم BFS است که راس‌ها را دقیقا به ترتیب کشف شدن پردازش می‌کند.

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن $x$ به انتهای صف |
| `pop()` | حذف عضو ابتدای صف |
| `front()` | دیدن اولین عضو |
| `back()` | دیدن آخرین عضو |
| `empty()` | آیا صف خالی است؟ |
| `size()` | تعداد اعضا |

```cpp linenums="1"

queue<int> q;

q.push(5);
q.push(8);
q.push(12);

cout << q.front() << endl; // 5
q.pop();
cout << q.front() << endl; // 8
```

همه‌ی عملیات‌های صف هم از $O(1)$ هستند.

### دکیو (Deque)

دکیو (Double Ended Queue) صفی است که از هر دو طرف می‌توان به آن اضافه یا از آن حذف کرد. این انعطاف باعث می‌شود در مسائلی مثل [پنجره‌ی لغزان](/Level2/stack/) و صف یکنوا خیلی به کار بیاید.

| تابع | توضیح |
|------|-------|
| `push_front(x)` / `push_back(x)` | اضافه کردن به ابتدا / انتها |
| `pop_front()` / `pop_back()` | حذف از ابتدا / انتها |
| `front()` / `back()` | دیدن اولین / آخرین عضو |
| `empty()` / `size()` | خالی بودن / تعداد اعضا |

```cpp linenums="1"

deque<int> dq;

dq.push_back(3);
dq.push_back(5);
dq.push_front(1);

cout << dq.front() << ' ' << dq.back() << endl; // 1 5

dq.pop_front();
dq.pop_back();

cout << dq.front() << endl; // 3
```

درج و حذف از دو سر دکیو $O(1)$ است و برخلاف `#!cpp queue`، در `#!cpp deque` می‌توان مثل آرایه با `#!cpp dq[i]` به اعضا دسترسی داشت.

### صف اولویت (Priority Queue)

گاهی ترتیب ورود مهم نیست و همیشه می‌خواهیم بزرگ‌ترین (یا کوچک‌ترین) عضو موجود را سریع در اختیار داشته باشیم. صف اولویت این کار را می‌کند و معمولا با داده‌ساختاری به نام هیپ (Heap) پیاده می‌شود. در STL، `#!cpp priority_queue` به طور پیش‌فرض بزرگ‌ترین عضو را بالا نگه می‌دارد (Max Heap).

| تابع | توضیح |
|------|-------|
| `push(x)` | اضافه کردن $x$ |
| `pop()` | حذف بزرگ‌ترین عضو |
| `top()` | دیدن بزرگ‌ترین عضو |
| `empty()` / `size()` | خالی بودن / تعداد اعضا |

```cpp linenums="1"

priority_queue<int> pq;

pq.push(7);
pq.push(2);
pq.push(15);
pq.push(10);

cout << pq.top() << endl; // 15
pq.pop();
cout << pq.top() << endl; // 10
```

`#!cpp push` و `#!cpp pop` از $O(\log n)$ و `#!cpp top` از $O(1)$ است.

#### کوچک‌ترین عضو

اگر به جای بزرگ‌ترین، کوچک‌ترین عضو را بخواهیم (Min Heap)، مقایسه‌گر `#!cpp greater` را می‌دهیم:

```cpp linenums="1"

priority_queue<int, vector<int>, greater<int>> pq;

pq.push(7);
pq.push(2);
pq.push(15);

cout << pq.top() << endl; // 2
```

!!! tip "نکته"
    یک ترفند رایج این است که به جای Min Heap، قرینه‌ی اعداد را در یک `#!cpp priority_queue` معمولی بریزیم. صف اولویت در الگوریتم‌هایی مثل دایکسترا و پریم و هر جایی که در هر مرحله «بهترین» گزینه را لازم داریم، استفاده می‌شود.

#### زوج‌ها و مقایسه‌گر دلخواه

خیلی وقت‌ها هر عضو صف اولویت چند مشخصه دارد؛ مثلا در دایکسترا هر عضو یک زوج (فاصله، راس) است و می‌خواهیم کمترین فاصله بالا باشد. چون زوج‌ها ابتدا بر اساس `#!cpp first` مقایسه می‌شوند، کافی است مقداری که اولویت را تعیین می‌کند در `#!cpp first` بگذاریم.

```cpp linenums="1"

priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;

pq.push({5, 1}); // (1)!
pq.push({2, 3});
pq.push({5, 0});

cout << pq.top().first << ' ' << pq.top().second << endl; // 2 3
```

1. زوج (فاصله، راس): اول فاصله مقایسه می‌شود و اگر برابر بود، شماره‌ی راس.

اگر ترتیب دلخواه پیچیده‌تری می‌خواهیم، یک مقایسه‌گر (Comparator) تعریف می‌کنیم: ساختاری که تابع `#!cpp operator()` آن دو عضو را می‌گیرد و می‌گوید اولی باید **پایین‌تر** از دومی قرار بگیرد یا نه.

```cpp linenums="1"

struct Cmp {
    bool operator()(const pair<int, int> &a, const pair<int, int> &b) const {
        return a.second > b.second; // (1)!
    }
};

priority_queue<pair<int, int>, vector<pair<int, int>>, Cmp> pq;

pq.push({1, 9});
pq.push({2, 4});

cout << pq.top().second << endl; // 4
```

1. اگر این تابع `#!cpp true` برگرداند، یعنی `#!cpp a` اولویت کمتری از `#!cpp b` دارد. این‌جا عضوی با `#!cpp second` کوچک‌تر بالا می‌آید.

!!! warning ""
    جهت مقایسه در `#!cpp priority_queue` برعکس چیزی است که معمولا انتظار داریم: مقایسه‌گر پیش‌فرض `#!cpp less` است و با این حال بزرگ‌ترین عضو بالا قرار می‌گیرد. پس هر وقت مقایسه‌گر دلخواه می‌نویسید، با یک مثال کوچک جهت آن را چک کنید.

### مجموعه (Set)

ست مجموعه‌ای از اعضای یکتا را به صورت مرتب نگه می‌دارد؛ اگر یک مقدار را چند بار درج کنیم فقط یک نسخه ذخیره می‌شود و اعضا همیشه بر اساس عملگر `#!cpp <` مرتب‌اند. به این ترتیب می‌توان سریع کوچک‌ترین، بزرگ‌ترین یا اولین عضو بزرگ‌تر یا مساوی یک مقدار را پیدا کرد. ست با یک درخت متوازن پیاده شده و همه‌ی عملیات اصلی آن $O(\log n)$ هستند.

| تابع | توضیح |
|------|-------|
| `insert(x)` | اضافه کردن $x$ |
| `erase(x)` | حذف $x$ |
| `find(x)` | ایتریتور به $x$ (یا `end()` اگر نباشد) |
| `count(x)` | آیا $x$ وجود دارد؟ (۰ یا ۱) |
| `lower_bound(x)` | اولین عضو بزرگ‌تر یا مساوی $x$ |
| `upper_bound(x)` | اولین عضو اکیدا بزرگ‌تر از $x$ |
| `begin()` / `rbegin()` | کوچک‌ترین / بزرگ‌ترین عضو |
| `empty()` / `size()` | خالی بودن / تعداد اعضا |

```cpp linenums="1"

set<int> st;

st.insert(5);
st.insert(2);
st.insert(8);
st.insert(5); // (1)!

for (int x : st)
    cout << x << ' '; // 2 5 8
cout << endl;

if (st.count(5))
    cout << "YES" << endl;

auto it = st.lower_bound(6); // (2)!
if (it != st.end())
    cout << *it << endl; // 8
```

1. مقدار $5$ قبلا وجود دارد و دوباره اضافه نمی‌شود.

2. اولین عضو بزرگ‌تر یا مساوی $6$ را می‌دهد.

!!! warning ""
    برای ست حتما از `#!cpp st.lower_bound(x)` استفاده کنید نه `#!cpp lower_bound(st.begin(), st.end(), x)`. نسخه‌ی دوم ساختار درختی ست را نمی‌شناسد و $O(n)$ طول می‌کشد.

### مولتی‌ست (Multiset)

مولتی‌ست همان ست است با این تفاوت که مقادیر تکراری را هم نگه می‌دارد. همه‌ی عملیات‌ها مثل ست $O(\log n)$ هستند.

```cpp linenums="1"

multiset<int> ms;

ms.insert(5);
ms.insert(5);
ms.insert(2);
ms.insert(5);

for (int x : ms)
    cout << x << ' '; // 2 5 5 5
cout << endl;

ms.erase(5); // (1)!

auto it = ms.find(2);
if (it != ms.end())
    ms.erase(it); // (2)!
```

1. دقت کنید که `#!cpp erase(x)` **همه‌ی** نسخه‌های $x$ را حذف می‌کند.

2. برای حذف فقط یک نسخه باید ایتریتور آن را به `#!cpp erase` بدهیم.

!!! tip "نکته"
    برای حذف یک نسخه از $x$ الگوی رایج `#!cpp ms.erase(ms.find(x))` است (قبل از آن مطمئن شوید $x$ وجود دارد). همچنین دقت کنید که `#!cpp ms.count(x)` از $O(\log n + k)$ است که $k$ تعداد تکرار $x$ است؛ اگر فقط می‌خواهید بدانید $x$ هست یا نه، از `#!cpp find` استفاده کنید.

### مپ (Map)

خیلی وقت‌ها می‌خواهیم به هر کلید یک مقدار نسبت دهیم؛ مثلا نام هر دانش‌آموز را به نمره‌اش، یا یک عدد بزرگ را به تعداد تکرارش. مپ مجموعه‌ای از زوج‌های (کلید، مقدار) را نگه می‌دارد که کلیدها یکتا و مرتب‌اند. پیاده‌سازی و پیچیدگی آن مثل ست است و عملیات اصلی $O(\log n)$ هستند.

```cpp linenums="1"

map<string, int> mp;

mp["Ali"] = 18;
mp["Sara"] = 20;
mp["Ali"]++; // (1)!

cout << mp["Ali"] << endl; // 19

if (mp.count("Reza"))
    cout << "found" << endl;

for (auto [name, score] : mp) // (2)!
    cout << name << ' ' << score << endl;
```

1. با `#!cpp []` می‌توان مقدار یک کلید را خواند یا تغییر داد.

2. پیمایش مپ به ترتیب کلیدها انجام می‌شود؛ هر عضو یک `#!cpp pair` است که `#!cpp first` آن کلید و `#!cpp second` آن مقدار است.

!!! warning ""
    اگر با `#!cpp mp[x]` به کلیدی دسترسی پیدا کنید که وجود ندارد، آن کلید با مقدار پیش‌فرض (مثلا صفر برای `#!cpp int`) ساخته می‌شود. مثلا شرط `#!cpp if (mp[x] > 0)` برای هر $x$ جدیدی که چک شود یک کلید به مپ اضافه می‌کند و هم حافظه و هم `#!cpp size()` را خراب می‌کند. برای این که فقط وجود کلید را چک کنید، از `#!cpp count` یا `#!cpp find` استفاده کنید.

### نسخه‌های نامرتب

اگر مرتب بودن اعضا برایمان مهم نیست و فقط درج، حذف و جستجوی سریع می‌خواهیم، می‌توانیم از `#!cpp unordered_set` و `#!cpp unordered_map` استفاده کنیم. این‌ها با جدول هش (Hash Table) پیاده شده‌اند و توابعشان تقریبا همان توابع `#!cpp set` و `#!cpp map` است، با این تفاوت که ترتیبی ندارند و `#!cpp lower_bound` ندارند. عملیات اصلی آن‌ها به طور میانگین $O(1)$ است.

```cpp linenums="1"

unordered_set<int> st;
st.insert(5);
st.insert(10);
if (st.count(5))
    cout << "YES" << endl;

unordered_map<string, int> mp;
mp["Ali"] = 18;
cout << mp["Ali"] << endl;
```

!!! warning ""
    در بدترین حالت، اگر اعضای زیادی در یک خانه‌ی جدول هش بیفتند، عملیات‌ها $O(n)$ می‌شوند. در کدفورسز گاهی تست‌هایی مخصوص همین حالت (anti-hash) ساخته می‌شود؛ اگر مطمئن نیستید، همان `#!cpp set` و `#!cpp map` انتخاب امن‌تری هستند.

### ایتریتورها

در داده‌ساختارهایی مثل `#!cpp set` و `#!cpp map` نمی‌توان با اندیس به اعضا دسترسی داشت. به جای آن STL از ایتریتور (Iterator) استفاده می‌کند که شبیه اشاره‌گری به یکی از اعضاست و می‌توان آن را جلو و عقب برد. خود ایتریتور فقط آدرس عضو است و برای خواندن مقداری که به آن اشاره می‌کند، درست مثل اشاره‌گرها، پشت آن ستاره می‌گذاریم: `#!cpp *it`. `#!cpp begin()` به اولین عضو و `#!cpp end()` به «بعد از آخرین عضو» اشاره می‌کند، پس هیچ‌وقت نباید مقدار `#!cpp *st.end()` را خواند.

```cpp linenums="1"

set<int> st = {2, 5, 8};

auto it = st.begin();
cout << *it << endl; // (1)!

++it;
cout << *it << endl; // 5

it = st.find(8); // (2)!
if (it != st.end())
    st.erase(it);

for (auto it = st.rbegin(); it != st.rend(); ++it) // (3)!
    cout << *it << ' '; // 5 2
```

1. `#!cpp it` به عضو اول یعنی $2$ اشاره می‌کند و `#!cpp *it` مقدار آن یعنی $2$ را می‌خواند. بدون ستاره، خود ایتریتور را داریم نه مقدار عضو را.

2. `#!cpp find` ایتریتوری به عضو برمی‌گرداند که می‌توان همان را به `#!cpp erase` داد.

3. `#!cpp rbegin()` و `#!cpp rend()` برای پیمایش از آخر به اول استفاده می‌شوند.

در `#!cpp map` هر عضو یک `#!cpp pair` است؛ پس `#!cpp (*it).first` کلید و `#!cpp (*it).second` مقدار آن است که معمولا به شکل کوتاه‌تر `#!cpp it->first` و `#!cpp it->second` نوشته می‌شود.

```cpp linenums="1"

map<string, int> mp = {{"ali", 20}, {"sara", 18}};

auto it = mp.begin();
cout << it->first << ' ' << it->second << endl; // ali 20
```

!!! tip "نکته"
    برای تعریف ایتریتور از `#!cpp auto` استفاده کنید تا لازم نباشد نوع طولانی آن را بنویسید. برای پیمایش ساده هم حلقه‌ی `#!cpp for (int x : st)` خواناتر است.

!!! danger "مهم"
    وقتی عضوی را حذف می‌کنید، ایتریتورِ همان عضو بی‌اعتبار می‌شود و استفاده از آن رفتار نامشخص دارد. پس هنگام حذف در حین پیمایش، ایتریتور بعدی را از خود `#!cpp erase` بگیرید:

    ```cpp linenums="1"

    for (auto it = st.begin(); it != st.end(); ) {
        if (*it % 2 == 0)
            it = st.erase(it); // (1)!
        else
            ++it;
    }
    ```

    1. `#!cpp erase` ایتریتور عضو بعدی را برمی‌گرداند؛ به همین دلیل در این حالت `#!cpp ++it` نمی‌نویسیم.

    در وکتور وضعیت سخت‌گیرانه‌تر است: `#!cpp push_back` ممکن است کل آرایه را به جای دیگری از حافظه منتقل کند و **همه‌ی** ایتریتورها و اشاره‌گرهای قبلی را بی‌اعتبار کند.

### کدام را انتخاب کنیم؟

| داده‌ساختار | مرتب | تکراری | درج / حذف | جستجو |
| :--- | :---: | :---: | :---: | :---: |
| `vector` | ✗ | ✓ | $O(1)$ انتها، $O(n)$ وسط | $O(1)$ با اندیس |
| `stack` | ✗ | ✓ | $O(1)$ | فقط بالا |
| `queue` | ✗ | ✓ | $O(1)$ | فقط ابتدا |
| `deque` | ✗ | ✓ | $O(1)$ (دو سر) | $O(1)$ با اندیس |
| `priority_queue` | بر اساس اولویت | ✓ | $O(\log n)$ | فقط بیشینه، $O(1)$ |
| `set` / `map` | ✓ | ✗ | $O(\log n)$ | $O(\log n)$ |
| `multiset` | ✓ | ✓ | $O(\log n)$ | $O(\log n)$ |
| `unordered_set` / `unordered_map` | ✗ | ✗ | $O(1)$ میانگین | $O(1)$ میانگین |

+ به دسترسی با اندیس نیاز دارید یا فقط به انتها اضافه می‌کنید: وکتور.
+ فقط آخرین عضو اضافه‌شده را لازم دارید: استک.
+ اعضا باید به ترتیب ورود پردازش شوند: صف.
+ درج و حذف از هر دو سر: دکیو.
+ در هر لحظه بزرگ‌ترین یا کوچک‌ترین عضو را می‌خواهید: صف اولویت.
+ اعضا باید مرتب باشند یا به `#!cpp lower_bound` نیاز دارید: ست و مپ (با تکرار: مولتی‌ست).
+ ترتیب مهم نیست و فقط سرعت می‌خواهید: نسخه‌های نامرتب.
