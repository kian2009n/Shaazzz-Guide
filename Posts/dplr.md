یکی از الگوهای معروف [برنامه‌نویسی پویا](/Level2/dp/)، دی‌پی بازه‌ای است. در این دسته از سوالات، حالت دی‌پی را با یک بازه $[l, r]$ از آرایه تعریف می‌کنیم؛ یعنی $dp[l][r]$ جواب مسئله را روی زیرآرایه‌ی $a_l, a_{l+1}, \dots, a_r$ نگه می‌دارد و از جواب بازه‌های کوچک‌تر (مثل $[l+1, r]$ و $[l, r-1]$) به دست می‌آید. چون هر بازه از بازه‌های کوتاه‌تر ساخته می‌شود، معمولا جدول را به ترتیب طول بازه پر می‌کنیم.

### مسئله‌ی بازی روی آرایه

یک آرایه‌ی $N$ عضوی داریم و آلیس و باب با آن بازی می‌کنند. آلیس شروع می‌کند و هر کس در نوبت خود یکی از دو عضو اول یا آخر آرایه را حذف می‌کند و اگر آن عضو $x$ باشد، $x$ امتیاز می‌گیرد. بازی تا خالی شدن آرایه ادامه دارد. اگر $X$ امتیاز آلیس و $Y$ امتیاز باب باشد، آلیس می‌خواهد $X - Y$ را بیشینه و باب می‌خواهد آن را کمینه کند. اگر هر دو بهترین بازی ممکن را انجام دهند، $X - Y$ در پایان چقدر است؟

??? success "راه حل"
    برای هر $1 \leq l \leq r \leq N$ مسئله را روی زیرآرایه‌ی $a_l, \dots, a_r$ در نظر می‌گیریم و $dp[l][r]$ را برابر مقدار $X - Y$ تعریف می‌کنیم، وقتی بازی از این بازه شروع شود و نفری که نوبتش است «نفر اول» حساب شود.

    حرکت اول را بررسی می‌کنیم. اگر نفر اول $a_l$ را بردارد، بازی روی بازه‌ی $[l+1, r]$ ادامه پیدا می‌کند و این بار حریف شروع‌کننده است؛ پس $dp[l+1][r]$ از دید حریف محاسبه شده و از دید نفر اول برابر $-dp[l+1][r]$ است. بنابراین این حالت $a_l - dp[l+1][r]$ امتیاز می‌دهد. به همین ترتیب اگر $a_r$ را بردارد، $a_r - dp[l][r-1]$ به دست می‌آید. چون نفر اول بهترین حرکت را انتخاب می‌کند:

    $$dp[l][r] = \max(a_l - dp[l+1][r],\ a_r - dp[l][r-1])$$

    پایه هم $dp[i][i] = a_i$ است و جواب مسئله $dp[1][N]$ است.

    ```cpp linenums="1"

    for (int i = 1; i <= N; i++)
        dp[i][i] = a[i];

    for (int len = 2; len <= N; len++) { // (1)!
        for (int l = 1; l + len - 1 <= N; l++) {
            int r = l + len - 1;
            dp[l][r] = max(a[l] - dp[l + 1][r], a[r] - dp[l][r - 1]);
        }
    }
    ```

    1. بازه‌ها را به ترتیب طول پر می‌کنیم تا وقتی به $[l, r]$ می‌رسیم، بازه‌های کوتاه‌تر آماده باشند.

    پیچیدگی زمانی $O(N^2)$ است، چون $O(N^2)$ بازه داریم و هر کدام در $O(1)$ محاسبه می‌شود.

### بلندترین زیردنباله‌ی پالیندروم

رشته‌ی $s$ به طول $n$ داده شده است. طول بلندترین زیردنباله‌ی آن که پالیندروم باشد چقدر است؟ (زیردنباله لازم نیست پیوسته باشد.)

??? success "راه حل"
    $dp[l][r]$ را برابر طول بلندترین زیردنباله‌ی پالیندروم زیررشته‌ی $s_l, \dots, s_r$ تعریف می‌کنیم. طبق تعریف $dp[i][i] = 1$ است و برای بازه‌ی طول ۲، اگر $s_i = s_{i+1}$ باشد $dp[i][i+1] = 2$ و در غیر این صورت $1$ است.

    برای محاسبه‌ی $dp[l][r]$ سه حالت داریم:

    1. $s_l$ در جواب نیست: جواب برابر $dp[l+1][r]$ است.
    2. $s_r$ در جواب نیست: جواب برابر $dp[l][r-1]$ است.
    3. هم $s_l$ و هم $s_r$ در جواب هستند: چون جواب پالیندروم است، این دو باید برابر باشند و در دو سر زیردنباله قرار بگیرند؛ پس به شرط $s_l = s_r$ جواب این حالت $dp[l+1][r-1] + 2$ است.

    همیشه یکی از این سه حالت رخ می‌دهد، پس:

    $$dp[l][r] = \max\big(dp[l+1][r],\ dp[l][r-1],\ [s_l = s_r] \cdot (dp[l+1][r-1] + 2)\big)$$

    ```cpp linenums="1"

    for (int i = 1; i <= n; i++) {
        dp[i][i] = 1;
        if (i < n) dp[i][i + 1] = (s[i] == s[i + 1] ? 2 : 1);
    }

    for (int len = 3; len <= n; len++) {
        for (int l = 1; l + len - 1 <= n; l++) {
            int r = l + len - 1;
            dp[l][r] = max({dp[l + 1][r], dp[l][r - 1],
                            (s[l] == s[r] ? dp[l + 1][r - 1] + 2 : 0)});
        }
    }
    ```

    پیچیدگی زمانی این راه حل هم $O(n^2)$ است.

!!! tip "نکته"
    در دی‌پی بازه‌ای معمولا جواب بازه‌ی $[l, r]$ یا از کنار گذاشتن یکی از دو سر بازه به دست می‌آید (مثل دو مسئله‌ی بالا) یا از شکستن بازه در یک نقطه‌ی میانی $k$ و ترکیب جواب $[l, k]$ و $[k+1, r]$ که در آن حالت پیچیدگی $O(n^3)$ می‌شود.
